# Myself IDE

**Своя IDE. Нужные инструменты. Меньше лишнего.**

Экспериментальный форк Code - OSS: упрощаем интерфейс и состав приложения, сохраняем инструменты разработки и добавляем удобную работу с документами.

## Зачем этот проект

Хочется IDE, состав и внешний вид которой можно подстроить под себя: писать код, работать с Git и терминалом, ставить нужные расширения, читать документацию и готовить обычные тексты. Встроенные AI-сценарии, аналитика и ненужные элементы интерфейса постепенно убираются из нашего форка.

Цель — уменьшить сложность, размер поставки и расход ресурсов. Измерений, доказывающих преимущество по RAM или скорости перед VS Code, пока нет. Мы развиваем существующую основу Code - OSS, сохраняя редактор и API расширений.

## Попробовать

1. Открой [релизы](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/releases) и скачай ZIP для macOS Apple Silicon. Там же лежит SHA-256.
2. Распакуй `Myself IDE.app`. Текущий preview имеет ad-hoc подпись и не notarized; другие платформы ещё не проверены.
3. Языковые инструменты ставь по необходимости через Open VSX или VSIX. Наличие расширения и его работоспособность в форке зависят от конкретного расширения.
4. Для PDF открой `.txt` и нажми **Export Text as PDF** в заголовке редактора либо **File → Export Text as PDF**.

PDF сейчас экспортирует обычный текст из текущего буфера, включая несохранённые изменения: A4, поля 20 мм, serif 12 pt, интервал 1.5. Markdown/HTML печатаются буквально. Опциональный редактор документов доступен через «Новый документ» и «Открыть как документ»: обычный текст, поиск, undo/redo, сохранение и Export PDF. В нём можно выбрать поля, семейство/размер шрифта и межстрочный интервал; параметры не записываются в текстовый файл.

## Ограничения preview

Это проект в разработке. Полное физическое удаление AI-кода ещё не завершено; сохранённый код GitHub-аутентификации требует собственной конфигурации приложения. SSH и остальные удалённые сценарии нуждаются в отдельных проверках. Однажды при ручном тестировании обычный профиль оставил пустое окно; причина пока не установлена, в изолированном профиле открытие и PDF работали.

Блокировка встроенной аналитики не запрещает сетевую работу Git, каталога или расширений, которые пользователь установит сам. Логи ограничены по каналам; общего лимита всех логов пока нет.
