## Зачем этот проект

Хочется IDE, состав и внешний вид которой можно подстроить под себя: писать код, работать с Git и терминалом, ставить нужные расширения, читать документацию и готовить обычные тексты. Встроенные AI-сценарии, аналитика и ненужные элементы интерфейса постепенно убираются из нашего форка.

Цель — уменьшить сложность, размер поставки и расход ресурсов. Измерений, доказывающих преимущество по RAM или скорости перед VS Code, пока нет. Мы развиваем существующую основу Code - OSS, сохраняя редактор и API расширений.

## Попробовать

1. Скачай ZIP из [0.0.8-preview](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/releases/tag/v0.0.8-preview) для macOS Apple Silicon. Там же лежит SHA-256.
2. Распакуй `Myself IDE.app`. Текущий preview имеет ad-hoc подпись и не notarized; другие платформы ещё не проверены.
3. Языковые инструменты ставь по необходимости через Open VSX или VSIX. Наличие расширения и его работоспособность в форке зависят от конкретного расширения.
4. Для нового документа выбери **File → New File… → New Document**. Для готового `.txt` нажми **Open as Document** в заголовке редактора. В режиме документа доступны поиск, сохранение, undo/redo, настройки страницы и **Export PDF**.
5. Для быстрого экспорта из обычного текстового редактора нажми **Export Text as PDF** в заголовке `.txt` либо **File → Export Text as PDF**.

PDF экспортирует обычный текст из текущего буфера, включая несохранённые изменения. Быстрый экспорт использует A4, поля 20 мм, serif 12 pt и интервал 1.5; в режиме документа поля, семейство/размер шрифта и интервал можно выбрать. Markdown/HTML печатаются буквально. Параметры оформления сохраняются только в текущем редакторе и не записываются в `.txt`; предварительный вид страницы приблизительный. В опубликованной 0.0.8 после первого Save As может открыться обычный текстовый редактор — **Open as Document** возвращает режим документа. В локальной 0.0.9 сохранение режима документа исправлено и проверено.

## Куда движемся

- Завершить очистку встроенного AI/MCP и оставшихся ненужных функций с проверкой зависимостей.
- Развивать готовый MVP редактора документов: уточнить модель хранения оформления и расширять сценарии учебных ответов и эссе.

- Исследовать встраивание Ghostty/другого терминального движка; сохранить рабочий вариант со штатным терминалом и shell-плагинами.
- Разработать новый бренд и настраиваемый интерфейс: кнопки, вкладки, панели, плотность и цвета.

## Ограничения preview

Это проект в разработке. Полное физическое удаление AI-кода ещё не завершено; собственный GitHub-вход и каталог отложены; обычные Git/SSH и API аутентификации расширений сохраняются. Remote SSH/удалённый сервер и туннели отложены для первого локального пакета; ручной ssh в терминале сохраняется. Однажды при ручном тестировании обычный профиль оставил пустое окно; причина пока не установлена, в изолированном профиле открытие и PDF работали.

Блокировка встроенной аналитики не запрещает сетевую работу Git, каталога или расширений, которые пользователь установит сам. Логи ограничены по каналам; общего лимита всех логов пока нет.
