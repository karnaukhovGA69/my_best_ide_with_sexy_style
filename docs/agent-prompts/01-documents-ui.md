# Промпт агента

```text
Работай только с нашим форком Myself IDE. Прочитай AGENTS.md, docs/development-plan.md, docs/document-export-contract.md и своё задание ниже. Не трогай оригинальный VS Code и upstream. Работай в отдельном checkout/worktree на своей ветке от актуального main с шестой итерацией; не переключай общий рабочий каталог. Проверь git status и базу до правок. Не запускай других агентов без отдельного поручения.

Не меняй чужие области, общие entrypoints, product/build/корневые зависимости/lockfiles. Не запускай полную сборку и не публикуй релиз. Делай релевантные локальные проверки, используй существующую инфраструктуру. Все нужные общие подключения передай интегратору. Итог: реальные изменения, проверки, коммит/ветка и собственный отчёт с ограничениями. Не объявляй готовым неподключённый end-to-end сценарий.

Задание documents-ui. Ветка agent/documents-ui. Твоя область: extensions/myself-documents/** и docs/agent-reports/documents-ui.md.

Сделай расширение для обычного текста учебных ответов и эссе: «Новый документ», опциональное «Открыть как документ» для .txt, удобный ввод без TeX/Markdown и видимая кнопка «Экспорт PDF». Реализуй custom text editor, сохраняя TextDocument, WorkspaceEdit, dirty/save/undo/redo и внешние изменения файла; не пиши файл напрямую в обход document API. Обычный текстовый редактор .txt остаётся доступен. Добавь выбор параметров из контракта PDF и понятный preview страницы; не обещай абсолютно точное совпадение preview с печатью без измерения.

Кнопка отправляет ровно DTO v1 команде myself.documents.exportPdf. Пока backend разрабатывается, тестируй adapter с mock: saved/cancelled/rejected/missing command. Не встраивай второй PDF backend. Не добавляй TeX, Chromium, AI, облако или редактор кода Monaco заново. Настройки страницы не портят .txt; Markdown parsing, таблицы и полный rich text отложены.

Приёмка: кириллица/английский, а)1 и б)3, эссе с пустыми строками; сохранение/переоткрытие/undo/redo/внешнее изменение без потери данных; кнопка доступна без Command Palette; ошибки/cancel корректны. Tests/manifest/build инструкции локальны твоему расширению. Build allowlist/product wiring делает integration. В отчёте укажи требуемые команды, активацию, build hook, ограничения доступности и как запускать тесты.
```
