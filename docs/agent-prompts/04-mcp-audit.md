Отдельно защити GitHub auth, SSH/remote extensions, обычные команды/IntelliSense и пользовательские расширения от ошибочного удаления. Не работай в ветке ai-terminal-cleanup, а пересечения опиши в отчёте. Не меняй контракт PDF, план и реестр владельцев.
