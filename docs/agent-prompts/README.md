# Запуск параллельных агентов

## Новое утверждённое задание — Nerded Code

От 6 ноября 2026: [06-nerded-code-visual.md](06-nerded-code-visual.md) — реализовать **Calmer Studio · Оригинал** с **цветными vscode-icons**, рабочее имя **Nerded Code**. [Полная спецификация](../nerded-code-visual-spec.md) содержит выбранные локальные макеты, токены, размеры, границы и критерии приёмки. Статус: готово к назначению после проверки владельцев UI; не выполнено. Историческая таблица ниже не отражает новых назначений и не заменяет свежие claims.

Для нового чата сначала дай [сводку контекста](../project-handoff.md). Открой наш репозиторий в отдельных рабочих каталогах от актуального main. Каждому агенту дай содержимое одного блока из файла ниже. Одно задание — один агент. Имена веток рекомендуемые; агент проверяет, что область и ветка не заняты. Эти файлы не запускают агентов автоматически.

Агенты не делят рабочий каталог. Сейчас уже заняты documents-ui и mcp-gallery-disable; не запускать их дубликаты. ai-terminal-cleanup можно назначить только после повторной проверки владельцев. Старый промпт mcp-audit не является поручением параллельно менять занятую MCP-область. Перед запуском проверь актуальные [отчёты](../agent-reports/integration.md), а не только эту таблицу.

Полные сборки запускает только интегратор на накопленный релизный пакет из нескольких изменений. Готовность отдельного агента не запускает сборку или релиз: агент передаёт код и результаты целевых проверок, интегратор проверяет весь пакет вместе. Документационные правки обходятся без сборки. Основные правила — в корневом AGENTS.md; распределение файлов и приёмка — в docs/development-plan.md.
