# appearance-style-menu

Статус: ГОТОВО к интеграции. Владелец: чат упрощения Myself IDE. Ветка: agent/appearance-style-menu. База: main 2880abbb1bb (либо актуальный main при создании ветки).

Область: новый contrib/modernUI/browser/appearanceActions.ts, только side-effect import нового модуля в modernUI.contribution.ts; существующий density menu сохраняется без изменений, новый test/browser/appearanceActions.test.ts. Обычный редактор: видимый выбор classic/modern layout и существующих default/compact density через Appearance и Settings menus. Не создавать второй density engine, не менять значения по умолчанию, темы/шрифты/данные, root entrypoints/build, GitHub и чужие claims. Дизайн: спокойный/последовательный UI, штатные menu controls и theme tokens, без новых CSS/анимаций. Существующая modernUI contribution уже подключена в workbench.common.main.

Уточнение после изучения существующего UI: density choices уже реализованы и покрыты тестами. Добавляется Classic/Modern submenu в Appearance и Settings, общий LayoutDensityMenu дополнительно доступен в Appearance; старый Settings density menu не переносится и не дублируется. Составное применение нескольких settings не нужно, rollback/preview не вводятся.

Результат: Interface Style submenu доступен в View > Appearance и Settings (GlobalActivity); два действия Classic/Modern используют существующий workbench.experimental.modernUI. Изменяется один параметр через штатное target resolution IConfigurationService; тема, editor font, tabs/density и прозрачность не сбрасываются. Существующий LayoutDensityMenu дополнительно доступен в Appearance только при Modern UI; прежний Settings density menu, команды и checked states сохранены. Никаких default configuration changes, новых CSS, network или startup mutations. Это первый шаг доступной настройки оформления, не полный визуальный ремастер/брендинг.

Проверки: 6 browser tests passed, 0 page errors — 4 новых menu/action/config failure tests и 2 существующих ModernUIContribution density tests. Scoped TypeScript 3 изменённых TS: 0 diagnostics; ESLint всех трёх TS и git diff --check passed. Первая проверка теста исправлена: MockContextKeyService.contextMatchesRules всегда возвращает false, поэтому тест теперь вычисляет настоящий context expression над значениями mock keys. Стили/геометрия не менялись; весь большой layout suite не запускался. Native меню/смена layout и темы high-contrast требуют smoke общего пакета; визуальный smoke в приложении ещё не выполнен.

Интегратору: дополнительного root wiring не требуется — appearanceActions импортирован существующей modernUI.contribution. Ветка не содержит отложенный GitHub каталог. Отложенная github-repository-catalog сохранена отдельно и исключена из релиза. Полный build/typecheck/native smoke выполнить в следующем общем пакете.
