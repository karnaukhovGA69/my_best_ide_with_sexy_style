# Вторая волна функций Nerded Code

Задание интегратора `development-wave-2`. База `e1d30d01782`. Владелец подтвердил реализацию всех 27 направлений из [реестра](../feature-roadmap.md). Локальные шаблоны проектов исключены. Перенос на Rust отложен. GitHub login/catalog остаётся отложенным по правилам поставки.

## Назначения и зависимости

| Задание | Владелец и область | Приёмка |
| --- | --- | --- |
| editor-language-actions | Интегратор. Контекстное меню штатного Organize Imports. | QA проверяет точные условия редактора и провайдера. Нативный цикл проверяет реальное изменение и Undo. |
| project-notes | Интегратор. Новая Project Notes contribution и её подключение. | QA проверяет изоляцию локальной рабочей области, независимые записи, отмену и изменения после открытия диалога. |
| project-toolchain-picker | Разработчик 3. Новая contribution выбора инструмента. | Архитектор и безопасник проверяют область конфигурации и Trust. QA проверяет multi-root, отмену и исходную запись Python. |
| file-history-preview | Разработчик проектных действий. Дополнение штатных Timeline и Local History. | Проверить текущий файл, принадлежность версии, сравнение и подтверждение при восстановлении. Ревью архитектуры, безопасности и QA. |
| local-docs-fulltext | Разработчик 2. Поиск по содержимому локальной библиотеки. | Проверить весь доступный корпус, отсутствие внешних чтений, отмену и открытие найденной статьи. Ревью архитектуры, безопасности и QA. |
| pdf-macros-backend | Разработчик backend документов. Валидация, разбор и рендер экспорта в своей области. | Независимая проверка запроса, экранирования, сохранения v1 и настоящего PDF после подключения UI. |
| project-task-output | Разработчик Tasks. Отдельное меню уже запущенных задач. | QA проверяет отмену, два одноимённых запуска и точную остановку выбранной задачи через штатную службу. |
| saved-workbench-layouts | Разработчик раскладки. Отдельная contribution и профильное хранилище. | Архитектор и QA проверяют сохранение и повторное применение, пропущенные панели и сохранность редакторов. |

Общие entrypoints и NLS подключает интегратор. Поиск, контекстная справка и PDF в библиотеке редактируют общие файлы расширения документов последовательно. PDF backend можно проверять параллельно с поиском. Наборы VSIX, раздельная поставка опциональных модулей, обновление и диагностика ресурсов зависят от подтверждённого владения файлами профиля. Запуск языкового архива ведётся отдельно от штатной установки VSIX.
