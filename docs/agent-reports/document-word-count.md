# Счётчик в режиме «Открыть как документ»

Часть [#24](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/issues/24). База `b6845b533576b929878593a18c203ecdc7ac2167`, ветка `agent/document-word-count`.

Раньше рядом с документом был только статус синхронизации. Теперь над текстом видны число слов и число символов с пробелами. Строка остаётся видимой при прокрутке. Счётчик работает с открытым текстом и несохранённым черновиком, обновляется при вводе, вставке, удалении и смене отображаемой версии.

- `extensions/myself-documents/src/view.ts`, `media/editor.css` и оба файла `l10n/bundle.l10n*.json` добавляют строку со статусом и показателями, английские и русские подписи.
- `webview/editor.ts` считает весь текущий текст один раз за кадр, когда он изменился. `Intl.Segmenter` с языком вебвью выделяет слова и графемы. Пробел, табуляция и перенос строки входят в число символов. Эмодзи `👩‍💻` и буква с комбинируемым акцентом считаются по одному символу. Переносы считаются по содержимому поля редактора, где CRLF представлен одним LF. Числа форматируются по языку вебвью. Сохранение, редакторский черновик, обмен сообщениями и CSP не менялись.
- `test/webview.test.cts` проверяет пустой документ, набор `Привет мир`, системную вставку через буфер Chromium и удаление до подтверждения правки хостом. Сценарий восстановления проверяет счётчики черновика и замены его версией файла.

До правки проверка упала на отсутствии счётчика. После правки на macOS ARM64 прошли все 71 тест расширения, целевой TypeScript, ESLint, сборка ресурсов вебвью и проверка путей ресурсов для пакета. Дополнительная проверка с настоящей оболочкой `src/vs/workbench/contrib/webview/browser/pre/index.html` в Chromium использовала её iframe и MessagePort с тестовым хостом. Русская версия показала `2/10 → 1/6 → 2/15 → 0/0`. Chromium зарегистрировал `insertFromPaste` при вставке из буфера. Окно IDE и десктопная маршрутизация Cmd+V в этой проверке не использовались.

Для приёмки в установленном Preview откройте новый пустой документ. Проверьте `0/0`, введите `Привет мир` и проверьте `2/10`. Удалите пробел и `мир`, проверьте `1/6`. Вставьте после `Привет` два пробела, `café` в разложенной форме, перевод строки, `👩‍💻` и табуляцию. Должно стать `2/15`. Выделите весь текст и удалите его. Должно снова стать `0/0`. Сохранение и экспорт для проверки не нужны. В длинном документе проверьте видимость строки при прокрутке.
