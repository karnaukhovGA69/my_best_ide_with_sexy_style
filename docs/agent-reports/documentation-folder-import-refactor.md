# Чтение файлов при импорте папки документации

Готово к независимому ревью. База `622e9283343` (усиленные тесты из PR #14), ветка `agent/documentation-folder-import-refactor`. [Задача #13](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/issues/13)

В `extensions/myself-documents/src/libraryImport.ts` обход отвечает за каталог, выбор файлов и общий бюджет. Новый приватный `readDocument` отвечает за открытие и ограниченное чтение одного файла. Вызывающий код, экспортируемые типы, лимиты и сортировка не меняются.

Сохранены проверка канонического пути, пропуск симлинков, `O_NOFOLLOW`, проверка обычного файла через открытый дескриптор, предел размера до выделения буфера, чтение не более исходного размера плюс один байт, отклонение роста файла, строгий UTF-8, отмена до и во время чтения и закрытие дескриптора в `finally`. После успешного чтения общий бюджет увеличивается на фактическое число прочитанных байт.

На macOS ARM64 с Node 24.22.1 и pnpm 12.16.0 команда `pnpm --dir extensions/myself-documents test` прошла до и после правки, 49/49. Дополнительно на двух скомпилированных версиях и временных папках проверены одинаковые результаты сортировки, фильтрации, точной границы совокупного бюджета и отклонения при превышении размера или глубины. Реальный файл был дописан в точке отмены после `stat`: обе версии отклонили рост. `git diff --check` прошёл.
