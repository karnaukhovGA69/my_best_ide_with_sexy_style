# documentation-imported-links

Статус: ГОТОВО, проверено для интеграции. Владелец: интегратор/documents agent. База: f669b3fb871 + готовое Markdown чтение. Область: extensions/myself-documents/src/library.ts (message link handler), test/library-host.test.cts, этот отчёт. Для импортированного HTML/Markdown source пуст: текущий UI предлагает Open in Browser, но абсолютная HTTPS ссылка не открывается. Исправить явное открытие HTTP(S) после подтверждения, сохранить запрет file/command/script/неизвестных relative paths и отмену после закрытия reader. Без автоматической сети и изменения layout.

Два новых host regression tests воспроизводили сбои до исправления. После исправления полный extension suite: 37/37 passed, host/webview compilation и ESLint passed, diff --check passed. HTTP(S) URL проверяется до предложения действия, openExternal вызывается только после выбора Open in Browser; отсутствие source у импорта не блокирует абсолютную ссылку. Для file/command/javascript/неизвестного relative URL кнопка не предлагается. Закрытие панели инвалидирует ожидающее подтверждение. Нативные проверки/полный package не запускались.
