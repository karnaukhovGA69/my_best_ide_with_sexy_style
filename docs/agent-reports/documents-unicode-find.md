# documents-unicode-find

Статус: ГОТОВО к следующему релизному пакету. Владелец: агент documents-save-as. База: 81efa000a9f. Ветка: agent/documents-unicode-find.

Область: extensions/myself-documents/webview/editor.ts, test/webview.test.cts и собственный отчёт. Исправить смещение выделения при поиске после Unicode-символов, меняющих длину при lowercase. Сохранить поиск без учёта регистра, буквальную обработку запроса и переход к началу. MCP/voice не затрагивать; сборка следующего релиза выполняется пакетом.

Результат: поиск выполняется по исходной строке через Unicode case-insensitive RegExp с экранированием пользовательского запроса. Индексы больше не смещаются из-за lowercase-преобразования İ; совпадения выделяются по фактической длине. Сохранены переход от текущего выделения и циклический поиск.

Проверено: компиляция TypeScript расширения/webview, 16 tests passed, ESLint webview, git diff --check. Новая browser-регрессия проверяет İ перед совпадениями, emoji, кириллицу без учёта регистра, Enter, повторный поиск/переход к началу, буквальные a+b/[x], отсутствие совпадений и отсутствие изменения текста. Первый прогон теста выявил неверное предположение фикстуры о позиции курсора; она теперь явно установлена в начало.
