# Ручные действия языка в редакторе

Задание `editor-language-actions`, владелец интегратор. База `e1d30d01782`. Область: `src/vs/editor/contrib/codeAction/browser/codeActionCommands.ts` и этот отчёт. Независимая проверка — QA.

«Переименовать символ» и «Форматировать документ» уже доступны в контекстном меню редактора и используют зарегистрированные языковые провайдеры. «Упорядочить импорты» использует тот же механизм EditorAction, но раньше не имело собственного пункта рядом с ними. Добавляем пункт в существующую группу редактора. Он виден для редактируемого документа, когда провайдер объявил соответствующее действие. Выбор вызывает штатное действие для этого редактора по запросу пользователя.

Проверить с провайдером, который поддерживает `source.organizeImports`: в контекстном меню три действия доступны по возможностям текущего файла, нажатие применяет обычную правку импортов. Документ без такого провайдера и просмотр только для чтения не показывают действие. После применения работает штатный Undo. Меню не добавляет новый обработчик сохранения или изменение language server API. Нативная проверка входит в общий пакет.
