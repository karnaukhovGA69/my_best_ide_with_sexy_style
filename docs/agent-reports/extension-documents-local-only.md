Chromium fixture с CSP, извлечённым из production template: до изменения 3 intercepted background requests, после 0; data image/nonce styles и ручная внешняя ссылка работают. Это целевые browser проверки, не packaged native smoke. Прямых вызовов new Extension не найдено; DI-инстанцирование покрыто тестами. Общая релизная интеграция, подпись и native smoke остаются у интегратора.
