# git-autofetch-disable

Статус: ГОТОВО к интеграции. Владелец: чат упрощения Myself IDE. Ветка: agent/git-autofetch-disable. База: main 9215f010f78. Claim 24db7b268ee.

Область: extensions/git/src/autofetch.ts и точечные регрессии, при необходимости repository.ts только точки подключения AutoFetcher. Исключить автоматический fetch/предложение его включить независимо от импортированных git.autofetch настроек. Сохранить ручные Fetch/Pull/Push и Git/SSH команды терминала. Дополнительно зарезервированы только extensions/git/package.json и package.nls.json для удаления двух устаревших настроек autofetch. Корневые manifests/build и security/trust не менять. Целевые проверки extension TS/lint и отсутствие таймеров/подписок/вызовов fetch; общий пакет у интегратора.

Результат: AutoFetcher физически удалён (143 строки), удалены import и обе точки создания из Repository, включая создание после выдачи Workspace Trust. Это удаление планировщика, а не ослабление trust gate: больше нечего запускать ни в trusted, ни в untrusted workspace. Таймер периодического fetch, configuration/metered/remote-operation listeners, уведомление с предложением включить fetch и запись настройки отсутствуют. Из extension manifest/nls удалены git.autofetch/git.autofetchPeriod. Импортированные старые значения не активируют код. Git команды/меню, ручной fetch/pull/push, существующее явное pull-before-checkout и остальные проверки Workspace Trust не изменены.

Проверки: весь проект TypeScript расширения Git — 87 файлов, 0 diagnostics; ESLint repository.ts и git diff --check passed. Пробная esbuild сборка только Git extension в памяти — 107 inputs, autofetch отсутствует; command/menu contributions побайтно-семантически равны базе, оба JSON валидны. Новые зеркальные unit-тесты не добавлялись: удалены все потребители и реализация; runtime/idle network smoke готового приложения остаётся обязательным этапом интегратора. Полная сборка приложения не запускалась. Начальный вызов CLI tsc не сработал из-за отсутствия bin/tsc у установленного TypeScript; проверка выполнена через его compiler API без установки зависимостей.
