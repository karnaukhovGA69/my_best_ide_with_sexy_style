# github-removal-settings-file-decision

Актуальное решение владельца от 6 ноября 2026 года, передано трём работающим чатам Myself IDE. Оно перекрывает прежние планы сохранить собственный GitHub-модуль и реализовать OAuth/catalog/private backup, а также промежуточное указание «пока не трогать».

GitHub-модуль не нужен: можно удалять специфичную GitHub-интеграцию после проверки потребителей, собственную GitHub-авторизацию, каталог GitHub-репозиториев и backup в приватном GitHub repo больше не планируем. Обычные Git, SSH, локальные репозитории, clone по URL и общую authentication/extension API сохраняем, если для их удаления нет отдельного решения. Это изменение продукта, не поручение удалить origin или менять GitHub-репозиторий разработки.

Вместо облачного backup: локальный файл настроек, видимые экспорт/импорт, пользователь выбирает файл и применяет изменения после просмотра; без собственного сервера, GitHub OAuth, фоновой синхронизации и автоматического восстановления при входе. Не включать токены/ключи/SecretStorage в экспорт.

Интегратору: согласованно обновить AGENTS.md, docs/project-handoff.md, docs/project-plan.md и docs/development-plan.md, чтобы новые агенты не восстанавливали отменённый модуль. Этот отчёт фиксирует решение; удаление GitHub runtime пока не заявляется выполненным.

Локальная задача settings-file-portability зарезервирована за чатом упрощения Myself IDE после inline-completions-runtime-disable. Работа будет в отдельной task-ветке; остальные агенты эту область не дублируют. Общие wiring/build/allowlist принадлежат интегратору.
