# github-repository-catalog

Статус: ЗАНЯТО. Владелец: чат упрощения Myself IDE. Ветка: agent/github-repository-catalog. База: main 9be3b2c89dc. Новое поручение владельца передано координирующим чатом 01a1a827-3022-7ff2-9970-43a31c3c7ab1: вернуть GitHub login + private repository catalog, без backup/AI/telemetry/issue uploads; прежний запрет auth/catalog отменён.

Зарезервированная область: новый extensions/myself-github/** (manifest, локализация, src, tests, compile config) и этот отчёт. В этой же задаче владелец auth, repository catalog UI, выбор одного root, проверка remote и root/owner/repo, clone/cancel/open; другим агентам не реализовывать дубликаты. Не изменять старый GitHub provider/portable engine, root manifests/allowlist/build/product или releaseNotesEditor. Интегратору потребуется только wiring новой extension в сборку после проверки.

Сеть только по действию пользователя для login/catalog/clone. Секреты только SecretStorage, без токенов в URI/args/logs/settings; собственный OAuth Device Flow требует Client ID приложения с включённым device flow (запрошен владельцу; secret не требуется). Сохранять Git/SSH/remote/workspaces/containers и обычную сеть процессов. Catalog перечисляет доступные приватные и публичные repositories, локальные копии ищет только внутри выбранного root. Не перезаписывать конфликты/посторонние каталоги, проверить traversal/symlink escape и remote, отмена/неуспешный clone не открывает проект. Отдельная панель каталога с видимым входом/выбором root/обновлением.

Промежуточно: создана изолированная repositoryIdentity основа — root/owner/name path, фиксированный GitHub clone URL и HTTPS/SSH remote matching с отказом traversal/credentials/чужим hosts. 4 Node tests passed, lint source passed. Это только первый слой: symlink/filesystem checks, clone lifecycle, login, API pagination и UI ещё НЕ реализованы, задача не готова к интеграции. Client ID пока отсутствует; пользователь запросил объяснение, регистрация OAuth app не выполнена. Старый vscode GitHub provider использует vscode.dev redirects; его бездумное возвращение не выбрано.

Промежуточный этап 2 (не готов к интеграции): добавлены LocalRepositories, GitProcess и RepositoryCatalog. LocalRepositories адресует только root/owner/name, проверяет canonical directories и inode/dev до/после операции, отказывает symlink target/.git/config, проверяет origin, резервирует новый destination эксклюзивно. Ошибка/отмена оставляет данные и sibling incomplete marker; автоматическое открытие/перезапись таких каталогов запрещены, автоматическое удаление пользовательских данных не выполняется. Защита от произвольного враждебного процесса, меняющего FS между системными вызовами, не заявляется: portable Node API не даёт atomic openat/no-follow для всего процесса Git. Связанные внешние worktrees через .git file пока консервативно отклоняются.

GitProcess запускает Git без shell, читает local origin с --no-includes, очищает inherited repository/config overrides, не выводит raw stderr и останавливает собственную process group при отмене на Unix. Windows taskkill путь реализован, но не запускался на этой macOS. Private clone пока использует только существующую системную Git credential configuration; bridge нового OAuth token ещё НЕ реализован, полноценная авторизация не готова.

RepositoryCatalog загружает одну страницу по явному вызову, fixed api.github.com/user/repos, token только Authorization header, redirects запрещены; пагинация не следует произвольному Link URL, avatars/resources не запрашиваются. Ответ ограничен фактическими 4 MiB, identities валидируются, ошибки не содержат response body. API покрыт synthetic fetch, живые приватные аккаунты/репозитории не использовались. Источники протокола: https://docs.github.com/en/rest/repos/repos и https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps .

Исправлен P2 параллельного review: .github/.github-private/_tools разрешены как repository name, owner не получает leading-dot разрешение; '.', '..', '.git'/'.GIT', traversal, separators и device names отклоняются. Проверки: 26 Node tests passed, source tsc -p extensions/myself-github/tsconfig.json и lint 4 source файлов passed. После финальной правки Git env и освобождения HTTP body повторены 9 затронутых тестов, tsc/lint passed. Присутствуют real Git local config test и real process cancellation, остальные clone/API операции fake/synthetic. UI/manifest/OAuth/SecretStorage/logout/credential bridge ещё впереди; не добавлять extension в публичный allowlist на основании этого промежуточного этапа.

Дополнительная интеграционная проверка core: реальный Git клонирует локальный synthetic bare fixture в зарезервированный пустой destination, затем origin нормализуется тестом к ожидаемому GitHub URL; prepare успешно возвращает путь и повторно открывает его без clone. GitHub network не используется. 13 LocalRepositories tests passed, общий набор теперь 27 проверок с переиспользованием неизменённых результатов. Этот тест подтверждает совместимость reserve-directory с git clone, не авторизацию приватного GitHub clone.
