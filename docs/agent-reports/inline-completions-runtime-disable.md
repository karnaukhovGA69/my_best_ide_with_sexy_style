# inline-completions-runtime-disable

Статус: ГОТОВО к интеграции. Владелец: чат упрощения Myself IDE. Ветка: agent/inline-completions-runtime-disable. База: main 62f2cc32a7c. Claim: 26b4f7f2c2e. Реализация и тесты: 80525f89d23.

Удалены регистрации editor InlineCompletionsController, 12 editor actions, toolbar/snooze actions, inline hover и accessible view, workbench language-status и provider-schema observers. Два contribution entrypoints оставлены пустыми для текущих imports. Из controller/commands.ts удалены три побочные Tab/Shift+Tab/Escape bindings, которые могли регистрироваться при импорте общими consumers. Не создаются стандартные per-editor inline models/views и их provider requests через эту регистрацию. Обычный SuggestController, completion API, типы/параметры/диагностика и регистрация extension providers сохранены.

Проверка потребителей: notebookEditorWidget, accessibleViewActions, InlineCompletionLanguageStatusBarContribution используют optional controller/model; bridge getInlineCompletionsController возвращает null без controller. InlineCompletionSchemaContribution не имеет внешних consumers. Общие реализации controller/model/view/commands, inline provider API, настройки editor.inlineSuggest, snooze service и части Chat остаются в исходниках и могут импортироваться другими модулями. Это удаление штатного generative inline runtime из регистраций, не удаление всего AI или запрет сетевой работы сторонних расширений.

Проверки: 10 browser Mocha tests passed в headless Chromium, 0 page errors (4 новых distribution/regression + 6 существующих Suggest). Проверены отсутствие controller/hover/accessible-view, inline commands/menu/keybindings при импорте обоих contribution entrypoints и command definitions, наличие обычных completion commands/keybindings, запрос и resolve метода после точки без вызова inline provider. Контроль через esbuild loader с production-файлами из 62f2cc32a7c: 2 ожидаемых assertion failures на inline registrations, 8 остальных tests passed. Старый код не записывался в checkout. Узкие TypeScript diagnostics четырёх файлов с ambient declarations — 0. Целевой ESLint четырёх файлов и git diff --check прошли. Первые проверки выявили неправильный слой нового теста и тип сравнения DI-конструктора: тест перенесён из editor в workbench, сравниваются prototypes без type casts. Полный client typecheck, package/native smoke/release не выполнялись.

Интегратору: объединить ветку в следующий пакет; дополнительного wiring нет. На общем output прогнать inlineCompletionsDistribution и Suggest suites; native smoke — обычные подсказки методов, Tab/Enter/Escape в suggest, отсутствие inline controller/actions. Scope: editor contribution/commands, workbench contribution, новый workbench test и отчёты. MCP/voice/documents/walkthrough, shared entrypoints/dependencies/build/main не менялись.
