# Продолжение нумерации в редакторе документов

Задача [#3](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/issues/3). База: `8c5155c82de`. Изменения готовы к проверке и интеграции. Область: `extensions/myself-documents/webview/editor.ts`, `extensions/myself-documents/test/webview.test.cts`.

Обычный Enter в конце строки вида `1) Первый пункт` вставляет новую строку с `2) ` и сохраняет отступ. Enter на пустом пункте убирает номер и оставляет строку для обычного текста. Перенос внутри строки, ввод с выделением, сочетания клавиш и завершение IME-ввода используют обычное поведение редактора.

Перенос и номер отправляются как одно изменение через существующий протокол синхронизации. После подтверждения изменения Undo работает через историю TextDocument. Дополнительных зависимостей и подключений в workbench не требуется.

Проверено командой `pnpm --dir extensions/myself-documents test`: сборка расширения и 52 теста прошли. Новые сценарии в Chromium проверяют сохранение отступа, переход с 9 на 10, курсор после номера, завершение списка, обычный Enter, отправку Undo после подтверждения изменения и видимость нового пункта в конце длинного документа. `git diff --check` прошёл. Нативная проверка в Nerded Code остаётся для общей сборки.
