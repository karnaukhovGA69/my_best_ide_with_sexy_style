# Локальная справка по контексту

Задание №14 `local-context-docs`. База `b03b7094146`, ветка `codex/local-context-docs`, код и тесты `7c0bcc2258f889c97dfba0db5b33ffe3db1462b0`. Изменены меню, локализации и хост библиотеки `extensions/myself-documents/`, а также целевые тесты и этот отчёт.

## Поведение

Действие **Локальная справка по контексту** доступно в контекстном меню текстового редактора при `editorLangId` Go, Rust, SQL или Shell Script. Обработчик получает активный редактор при вызове, читает только выделение или область под курсором до 64 UTF‑16 единиц и игнорирует аргументы команды. Rust и Shell Script сразу используют справочник языка. Справка открывается через существующий `DocumentationLibrary.open` в правой панели с `preserveFocus: true`.

| Контекст | Статья из активного локального каталога |
| --- | --- |
| Go `map` | `go/go-spec.html#Map_types` |
| SQL `SELECT` | `postgresql/sql-select.html` |
| SQL `CREATE TABLE` | `postgresql/sql-createtable.html` |
| Go и SQL без точного совпадения | `go/go-spec.html` или `postgresql/index.html` |
| Rust и Shell Script | `rust/rust-reference.html` или `bash/bash.html` |

Таблица содержит фиксированные пути и фрагменты. SQL сопоставляется без учёта регистра, а `CREATE TABLE` распознаётся в выделении и как фраза под курсором на одной строке. Для неизвестного термина или отсутствующей точной статьи открывается справочник того же языка из текущего каталога. При прямом вызове без редактора, при неподдерживаемом языке либо при отсутствии подходящей локальной статьи команда показывает пояснение. Тексты сообщений локализованы на английский и русский.

Перед использованием каталога и после чтения статьи проверяются активный редактор, документ, версия, язык и границы выделения. Более новый вызов или переход библиотеки отменяет устаревшее открытие. Подписки на активный редактор, курсор или текст не добавлены. Используются только разрешённые HTML/Markdown записи официального локального каталога и штатная проверка чтения. Выделение и аргументы команды не становятся путём или URL. Команда не обращается к LSP, сети или браузеру.
