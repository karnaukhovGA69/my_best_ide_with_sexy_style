# Локальный предпросмотр JSON и CSV

Задача `local-data-preview` (№25), база `82353c86aee`, ветка `codex/local-data-preview`, код и тесты `239ea88bd525d3669efb9e9827037c378344018b`. Изменения ограничены новым `extensions/myself-data-preview/**` и этим отчётом. Расширение готово к независимой проверке и сборке отдельного VSIX.

Откройте локальный `.json` или `.csv` и нажмите **Open Data Preview** в заголовке редактора. Действие читает только активный буфер, включая несохранённые изменения. Панель открывается рядом с текстом и сохраняет фокус в редакторе. Повторное действие обновляет одну панель. Проверка размера в символах происходит до `getText()`, а лимит UTF-8 проверяется до разбора. Действие не принимает внешний URI для просмотра.

Строгий JSON показывается деревом на нативных HTML-элементах `details` и `summary`. Поддерживаемый runtime передаёт исходную запись числа из `JSON.parse` reviver, даже когда значение не представимо точно как JavaScript Number. При повторяющемся ключе отображается последнее значение по правилам `JSON.parse`. У CSV с запятыми каждая строка считается данными, колонки нумеруются. Кавычки, двойные кавычки внутри поля, пустые ячейки и вложенные переводы строки сохраняются. Неподдержанный формат, некорректный ввод и превышение лимита дают отдельные сообщения. Поддерживаются только локальные `file:` URI без authority. Содержимое редактора остаётся доступным для правки в исходном текстовом представлении.

Лимиты: 1 МиБ UTF-8 на вход, 200 записей и 40 полей на запись CSV, 32 вложенных контейнера и 2048 значений JSON, 512 КиБ сгенерированного HTML. Предпросмотр строится по явному действию, с фиксированным CSS на токенах темы. В Webview отключены скрипты и command URI, список resource roots пуст. Политика ресурсов разрешает только встроенный CSS с nonce. Содержимое, включая формулы CSV и HTML в полях, экранируется перед включением в текстовые узлы.

Интеграция: включить исходный коммит, оставив расширение вне списка встроенной поставки. Подготовить отдельный VSIX командами из `extensions/myself-data-preview/README.md`. В готовом IDE установить через **Extensions → Install from VSIX…** по явному действию. Отключение и удаление работают штатными средствами расширений. Общие registration, package/lockfiles и новый runtime не требуются.
