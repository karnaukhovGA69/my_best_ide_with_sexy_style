# local-documentation-library

Статус: ГОТОВО к интеграции. Ветка: `agent/local-documentation-library`. База: `4ae3c2e857f` (claim; перед реализацией актуальный main). Владелец: чат упрощения Myself IDE, по прямому запросу владельца объединить готовые изменения и добавить локальную документацию перед визуальным ремастером.

Область: extensions/myself-documents (новые library host/view/webview/content/tests, подключение к существующему activation/build extension), этот отчёт. Видимая библиотека официальной документации Go, Rust, PostgreSQL, Bash и Linux; offline чтение рядом с кодом, локальный импорт, источники/версии/лицензии. Скачивание официальных материалов выполняется только сейчас по прямому поручению, в runtime сети/автообновления нет. Библиотека входит в уже разрешённый builtin myself-documents, без нового root allowlist. Полный package пока не запускать: пользователь уточнил «не билд, а замержь».

Координация интеграции: текущие готовые cleanup ветки проверяются по ancestry/diff и отчётам. GitHub catalog/auth исключены как отложенные; источники/аудиты не считать новой реализацией. Существующий интегратор продолжает собственные зарезервированные проверки; его checkout/main незакоммиченные изменения не трогать. После готовности библиотеки требуется включить её в общий main, а не оставлять только task-ветку.


## Реализация

Встроенная библиотека в уже поставляемом `myself-documents`: отдельный значок книги/TreeView, пять групп, поиск по названиям, webview reader рядом с кодом, оглавление, Back, встроенный Find и явное открытие источника. Импорт локальных HTML/HTM/MD/TXT копирует UTF-8 файл до 16 МиБ в globalStorage; список сохраняется в globalState, удаляется только копия. Markdown/TXT читаются как текст. Английская и русская локализация интерфейса, тема IDE.

Снимок официальных оригиналов от 2026-11-06: Go (spec, Effective Go, Memory Model), Rust (полные Book, Reference, Rust by Example), PostgreSQL 18.6 (1148 страниц), Bash 5.3 (полное Reference Manual), Linux man-pages 6.20 (3151 страница). Всего 4306 записей; примерно 56 МиБ с каталогом и лицензиями. Go/Rust явно помечены датой снимка. Linux — именно man-pages, не полный набор документации всех дистрибутивов.

Источники/версии/SHA-256/лицензии сохранены в `documentation`; Linux HTML получен mandoc, исходный архив с per-page notices поставляется. Остальные HTML сохранены из оригиналов. Подготовка снимка — отдельный ручной Python script с сетью; runtime/build/tests его не вызывают. Кэш скачивания исключён из Git/поставки.

Читатель строит разрешённый DOM заново, не переносит исходные CSS/скрипты/формы/изображения/URL ресурсов. CSP запрещает connect/frame/object/media/font; локальные roots ограничены собственными JS/CSS. Ссылки разрешаются только на записи каталога; внешние HTTP(S) открываются по отдельному явному действию. Все пять наборов проверены браузером без внешних запросов. Исходные имена Linux с `::` приведены к переносимым именам файлов, названия и source URL сохранены.

## Интеграция и ограничения

Слить ветку в main. Новые root allowlist/entrypoints/зависимости не нужны: `myself-documents` уже builtin. Новые локальные материалы должны попасть в package вместе с `out/webview/library.js`, `media/library.css/svg`, каталогом и всеми лицензиями; `.downloads` и maintainer script исключены через `.vscodeignore`. При будущем общем package проверить это фактическим списком файлов, открыть reader в native IDE, проверить поиск/оглавление/локальный импорт после перезапуска/тему/русский интерфейс и отсутствие сети. Нативные проверки нового reader и screen reader пока не выполнены; это не заявка на готовый установленный бинарный релиз.

Ограничения первой версии: поиск каталога по названиям, поиск внутри страницы через Find; картинки/встроенные стили подавлены; PDF/папки/полнотекстовый индекс всех книг/форматирование импортированного Markdown не включены. Это заготовка локальной библиотеки для пользовательского тестирования перед визуальным ремастером.
