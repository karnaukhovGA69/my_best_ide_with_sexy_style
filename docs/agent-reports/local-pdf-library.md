## Импорт и удаление

В правой панели **Документация** действие **Добавить PDF в библиотеку** открывает диалог выбора одного файла. Принимается локальный обычный файл с расширением `.pdf` до 16 МиБ. Чтение проверяет канонический путь, размер и идентичность файла, отклоняет символическую ссылку и файл, изменившийся в процессе чтения. Достаточно узнаваемого заголовка `%PDF-x.y`. Глубокая валидация структуры, страниц и активных элементов принадлежит проверенному просмотрщику.

Новая запись хранится с `format: 'pdf'`. Байты копируются без декодирования в `pdf-imports/<uuid>.pdf` под локальным хранилищем расширения. В карточке сохраняются имя и внутренний ID копии, исходный путь не сохраняется. Запись видна в **Мои документы** и в поиске по названиям. Выбор созданной записи сообщает, что проверенный просмотр внутри библиотеки пока недоступен. PDF исключены из текстового каталога, полнотекстового поиска и HTML-читателя.

Для удаления зарегистрированной записи требуется подтверждение **Удалить копию PDF**. Операция использует путь из зарегистрированной записи. При сбое сохранения метаданных файл остаётся. При ошибке удаления код пытается восстановить регистрацию. Файл, подменённый символической ссылкой, сохраняется вместе с исходным документом.

Все операции используют существующую последовательную очередь мутаций. За вызов импортируется один файл, чтение ограничено размером документа плюс один байт для проверки роста. Отмена диалога завершает вызов до чтения, закрытие расширения проверяется между этапами. Уже начатая запись метаданных завершается вместе со своей копией. Не зарегистрированная копия откатывается по пути и идентичности эксклюзивно созданного файла. Существуют промежутки между файловыми операциями и записью метаданных, поэтому принудительное завершение процесса или отказ файловой системы могут оставить незарегистрированные байты. Импорт не устанавливает суммарную квоту хранения.

## Проверка установленного просмотрщика

Установленный пакет `macromeer.pdfjs-viewer` 2.0.1 содержит PDF.js 6.4.299 и custom editor `macromeer.pdfPreview`. Совпадение подтверждено в манифесте и `out/src/pdfProvider.js:43`. В `out/src/pdfPreview.js:114–119` включены скрипты webview, корень ресурсов — только `lib` расширения. В `out/src/pdfPreview.js:198–224` файл загружается как локальные байты. В `out/src/pdfPreview.js:282–310` политика stock HTML заменяется на `default-src 'none'`, nonce для скриптов, `wasm-unsafe-eval`, `connect-src` от webview и `form-action 'none'`. В `lib/main.js:184–201` отключены образец по умолчанию, PDF JavaScript и редактирование аннотаций. Правила CSP установленные файлы меняют только при создании своей webview, запущенная среда здесь не проверялась.

Блокер для адаптера — автоматическая подготовка печати. `lib/web/viewer.mjs:19809–19811` запускает `_initializeAutoPrint` при загрузке страниц. В `19892–19917` проверка может перейти к `triggerPrinting` даже с выключенным PDF JavaScript. PDF.js оборачивает `window.print` и запускает рендер страниц в `8962–8989`. Блокировка нативного диалога в sandbox не доказывает отсутствие подготовки печати. В продукте отсутствует вызов просмотрщика, а установленный пакет и CSP оставлены без правок.

Вариант для архитектуры и безопасности без новой зависимости — проверенная версия того же локального custom editor с отключённым автоматическим запуском печати. Для строгого профиля просмотра можно отключить `supportsPrinting` в `PDFViewerApplicationOptions` до инициализации. Перед подключением проверить ограничения форм/XFA и запуск без внешних запросов на синтетических PDF. После этого ожидаемая точка интеграции — `vscode.openWith` с точным `macromeer.pdfPreview` только для действительного ID библиотеки, канонической копии и проверенной версии пакета.

Синтетические фикстуры покрывают сохранение бинарных байтов, список и поиск по названию, исключение из полнотекстового поиска, локальность и ограничения размера, отмену, откат регистрации, конфликт и подмену файла, подтверждение удаления, сохранение оригинала и отказ от предпросмотра.
- Статическая проверка манифеста и английской и русской локализации, а также `git diff --cached --check` прошли. Нативная IDE, личные PDF, ESLint и полная сборка в этой задаче не запускались.

Общие зависимости, сборка и точки входа не требуют изменений. Для интеграции готов срез импорта, списка и удаления. Приёмка встроенного просмотра остаётся отдельной после проверки пригодной версии просмотрщика.
