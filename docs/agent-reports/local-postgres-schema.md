## Контракт

- Опциональное desktop-расширение. Пункт **Посмотреть локальную схему PostgreSQL…** доступен в панели и контекстном меню SQL-редактора. Runtime проверяет Workspace Trust, локальное окно macOS/Linux и принадлежность обычного file URI папке открытого workspace. Command args игнорируются. Смена редактора или набора папок отменяет текущую операцию. Смена набора папок также закрывает предыдущий просмотр.
- Пользователь выбирает установленный `psql` и каталог существующего Unix-сокета. Модель валидирует абсолютные пути, исключает список хостов, ограничивает имена базы и роли ASCII-идентификаторами, порт числом 1–65535. Проверяет типы файлов, биты записи файла и каталога для группы и остальных, право исполнения файла и тип сокета. Симлинк на бинарник разрешён через показ разрешённого пути. Симлинк вместо сокета отклоняется. Модальное подтверждение показывает разрешённые пути, базу и роль и сообщает о запуске внешнего процесса. После подтверждения повторяются проверка идентичности файлов и проверка контекста.
- Единственный запуск через `spawn` с абсолютным путём, `shell:false`, `cwd:'/'`, отключённым stdin и фиксированным списком переменных окружения. `-X -w` отключают startup script и запрос пароля. Единственный параметр host — абсолютный каталог. Формируемый приложением conninfo передаёт `require_auth=none`, `passfile=/dev/null`, `connect_timeout=3`. Поддерживаются соединения, уже работающие без клиентской аутентификации, например существующий peer. Запрос аутентификации и старая libpq без требуемой опции дают явный отказ. Расширение не получает SQL из редактора, настройки соединений, историю, файл паролей или учётные данные. [psql](https://www.postgresql.org/docs/18/app-psql.html) · [Опции libpq](https://www.postgresql.org/docs/18/libpq-connect.html)
- Один фиксированный SQL-запрос читает доступные столбцы из `information_schema.columns` в read-only транзакции, увеличивая выборку до 501 строки для признака усечения. После 8 секунд, отмены или превышения 256 КиБ stdout / 8 КиБ stderr отправляется `SIGKILL` дочернему процессу и закрываются его потоки. Сырые ошибки не выводятся. Не более 500 строк в статическом просмотре. Все поля экранированы. Webview без скриптов, командных URI и ресурсов, со статическим CSP.

## Приёмка и ограничения

Контракт готов к независимой проверке архитектуры, безопасности и QA. Подтверждение ревью в этом срезе отсутствует. Для интегратора точка подключения — опциональное расширение в `extensions/myself-postgresql-schema`, единственная команда `myself.postgresqlSchema.open`. Обязательной зависимости, общей регистрации или изменения продуктовой сборки здесь нет. Нативная проверка меню, диалога и webview остаётся пакетной. VSIX не собирался и не устанавливался.

Выбранный исполняемый файл запускается с правами пользователя. Проверка путей подтверждает их состояние в моменты чтения метаданных. Одновременная замена пути средствами ОС, сетевое монтирование путей и внешний процесс, перенаправляющий выбранный Unix-сокет, остаются за пределами этой проверки. Нативный Linux и более ранние версии libpq не проверялись. Произвольный SQL, табличные данные, browsing через TCP, сохранение подключений, установка инструментов и механизмы передачи учётных данных находятся вне первого среза.
