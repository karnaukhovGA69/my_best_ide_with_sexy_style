# Проверка SHA-256 локального набора VSIX

База `7f3a643fe9de82de062c5b21197b8349f400412e`, ветка `codex/local-vsix-set-checksums`. Код `568d7546e31d46ab7b7d501ae11e0af64a906544` готов к независимой проверке. Изменения продукта и тестов ограничены `src/vs/workbench/contrib/myselfVsixSets`.

## Поведение

В меню Extensions команда **Preview Local VSIX Set…** читает выбранный JSON. Кнопка **Check SHA-256** в диалоге явно разрешает прочитать перечисленные в манифесте файлы рядом с ним. **Close** завершает просмотр. Проверка заново получает зарегистрированный провайдер `file:`, работает с одним архивом за раз и показывает по одному статусу на пакет. **Match** и **Mismatch** относятся к заявленной сумме, **File missing** означает явную ошибку отсутствия файла от провайдера, **Unavailable** охватывает другие ошибки, неподходящий тип файла, изменения метаданных и превышение лимитов. Диалог передаёт строки в штатный текстовый рендерер. Совпадение суммы подтверждает прочитанные байты относительно манифеста. Подпись, издатель и безопасность установки остаются непроверенными.

Метаданные немедленного каталога должны иметь точный тип Directory, а архивы — File. Статические ссылки и специальные файлы исключаются до открытия. Чтение ограничено заявленным размером до 32 MiB плюс байт для проверки конца файла. Общий предел включает все полученные байты, включая байт проверки роста, и составляет 128 MiB. На каждом архиве резервируется место для проверки конца, поэтому файл может быть пропущен на границе общего лимита. Провайдеру запрашиваются блоки до 1 MiB. Web Crypto получает один буфер архива за раз. Временные копии при передаче данных и вычислении суммы возможны. При отмене текущий дескриптор закрывается после возврата уже начатого вызова, следующие архивы пропускаются и диалог проверки не открывается. Замена провайдера также останавливает чтение.

Работа использует только локальные пути из проверенного манифеста. Запросы к галерее, URL, открытие содержимого архивов, запуск и установка отсутствуют. Провайдер проверяет тип и доступные метаданные по пути, его API не даёт атомарного открытия с запретом перехода по ссылке или сравнения идентичности уже открытого файла. Результат относится к снимку прочитанных байтов. Лексический локальный каталог может находиться на подключённой сетевой файловой системе, а его предки могут разрешаться операционной системой через ссылки.

## Проверка и интеграция

24 теста прошли через отдельную esbuild-транспиляцию и Mocha TDD на Node v26.8.2, macOS ARM64. Набор включает 6 тестов схемы, 11 тестов диалога и 7 тестов вычисления сумм с Web Crypto. Проверены отсутствие чтения архивов до подтверждения, отмена без частичного результата, статусы настоящих сумм, неприемлемые типы, рост и уменьшение файла, точный бюджет чтения, отсутствие провайдера и его замена с открытым дескриптором. Целевой TypeScript выдал ноль диагностик. Целевой ESLint прошёл с отключённым правилом `local/code-import-patterns` при использовании конфигурации из другого checkout. `git diff --cached --check` прошёл. Тесты диалога используют настоящий реестр команд и подставные picker/dialog/progress. Тесты провайдера используют синтетические файлы.

Текущий импорт в `workbench.desktop.main.ts` и ресурс `vs/workbench/contrib/myselfVsixSets` в `build/lib/i18n.resources.json` покрывают изменения. Перед упаковкой интегратору нужен обычный целевой lint с правилами своего дерева. Нативная приёмка в пакете проверяет меню, кнопку, закрытие по Escape, отмену через уведомление и результаты для правильного, изменённого и отсутствующего архива из синтетического набора. Нативный запуск и полная сборка в рамках задачи не выполнялись.

Будущая установка требует самостоятельной проверки подписей и метаданных пакета, совместимости, зависимостей и привязки к профилю. Установщик должен проверять те байты, которые он применяет. Итог текущего просмотра нельзя использовать как разрешение на установку или как гарантию будущего содержимого файла.
