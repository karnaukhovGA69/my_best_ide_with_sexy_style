# lsp-local-archive — локальные пакеты языковых серверов

Первый этап [#4](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/issues/4). Ветка `agent/lsp-local-archive` от `8c5155c82de`. Готов к ревью на macOS ARM64.

Раньше пользователь мог установить готовое языковое расширение из VSIX. Теперь отдельный VSIX добавляет в Explorer панель **Language Server Packages** с импортом локального ZIP, выбором бинарника и удалением установленной копии. Каталог общий для профилей IDE. Пакет хранится с отметками «издатель не проверен» и «требуется проверка перед запуском».

- `extensions/myself-language-servers/src/archive.ts` снимает ограниченную приватную копию ZIP, проверяет список путей и локальные заголовки, извлекает обычные файлы, сверяет объёмы и CRC-32. Проверка Mach-O различает ARM64 и совместимый universal, проверяет таблицу команд загрузчика. Поддерживаются ZIP до 128 МиБ, до 512 МиБ распакованных данных, до 256 МиБ на файл, до 4 096 записей и 16 сегментов. Неизвестные дополнительные поля ZIP отклоняются.
- `src/store.ts` вычисляет SHA-256 снимка и дерева файлов, записывает манифест отдельно от payload и публикует UUID-каталог одним rename. Отмена сохраняет другие установки. Удаление сначала атомарно скрывает пакет, затем удаляет его файлы. **Refresh** повторяет незавершённую очистку после перезапуска. Список читает только опубликованные пакеты.
- `src/extension.ts` и `package.json` подключают команды в Explorer. Удаление требует подтверждения с указанием области профилей. Импорт читает только выбранный локальный архив.
- `esbuild.mts` и `package-vsix.mts` собирают самостоятельный VSIX через существующие esbuild и VSCE. Парсер `yauzl@3.3.1` и его закреплённые зависимости включены в bundle вместе с их лицензиями. Общие манифесты и lockfiles IDE не менялись.

Все извлечённые файлы имеют права 0600, каталоги — 0700. Архивный SHA-256 фиксирует локальный снимок; он не удостоверяет издателя. Перед следующим этапом нужно подтвердить происхождение и целостность дерева, применить системную проверку quarantine и Gatekeeper и согласовать удаление пакетов с привязками и живыми процессами. Windows и обработка MOTW требуют отдельного этапа. Форматы .gz, .tar.gz и готовый отдельный бинарник пока вне этого VSIX.

## Проверки и приёмка

На macOS ARM64 прошли 25 тестов под `sandbox-exec` с `deny network*`, включая распакованный bundle VSIX с имитацией API IDE. Проверены реальный вложенный Mach-O и соседний ресурс, SHA-256, CRC-32, права, отмена, подмена исходного ZIP после осмотра, два экземпляра общего каталога, конкурентное удаление, очистка после перезапуска, выход пути за корень, симлинки и спецфайлы, коллизии регистра и Unicode, нарушенные заголовки и превышение лимитов. Целевые TypeScript и ESLint прошли. Node 24.22.1 из установленного Electron предоставляет используемый `zlib.crc32`. Запуск окна IDE и полный пакет приложения остаются на интеграционную приёмку.

```sh
./node_modules/.bin/tsc -p extensions/myself-language-servers
node extensions/myself-language-servers/package-vsix.mts
LANGUAGE_SERVERS_TEST_VSIX="$PWD/.build/vsix/myself.myself-language-servers-0.1.0.vsix" \
  /usr/bin/sandbox-exec -p '(version 1) (allow default) (deny network*)' \
  node --test extensions/myself-language-servers/test/*.test.cts
node build/eslint.ts 'extensions/myself-language-servers/**/*.{ts,mts,cts}'
git diff --check
```

1. Установить VSIX в отдельный профиль macOS ARM64. В Explorer открыть **Language Server Packages** и выбрать **Import ZIP**.
2. Выбрать тестовый ZIP с готовым ARM64 Mach-O и соседним ресурсом. Убедиться, что выбор показывает нужный относительный путь и хэш. Подтвердить выбор. Пакет должен появиться в списке, а маркер запуска тестового бинарника должен отсутствовать.
3. Открыть второй профиль, обновить список и убедиться, что пакет виден. Удалить его из первого профиля, подтвердить общую область, обновить второй профиль. Сверить отсутствие установленной копии и сохранность исходного ZIP.
4. Повторить импорт с отменой при выборе и с повреждённым ZIP. Сверить, что в списке отсутствуют частичные установки.
