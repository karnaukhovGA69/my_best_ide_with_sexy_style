# nerded-calm-preset

Статус: ЗАНЯТО. Владелец: интегратор. База: 41c3dd005c4. Область: src/vs/workbench/contrib/modernUI/browser/appearanceActions.ts, новый calmerStudioPreset.ts, test/browser/appearanceActions.test.ts и calmerStudioPreset.test.ts; этот отчёт. Подключить полный согласованный preset после готового nerded-calm-layout: Nerded Calm + nerded-calm-file-icons + workbench.calmerStudio=true + workbench.experimental.modernUI=false. Layout владелец уже реализует enum workbench.calmerStudio и helper isCalmerStudio, сами layout/metrics/CSS не менять.

Требования: явная видимая команда Calmer Studio в существующем Appearance/Settings меню; Classic/Modern корректно снимают Calmer флаг. Автоматически только новый profile storage и без явно выбранных theme/icon/layout значений; существующие профили не переписывать. Не сбрасывать fonts, color/token overrides, размеры/терминал/пользовательские настройки. Обработка storage marker после успеха, write failure не выдавать за успех. Расширять profile/defaults scope только при необходимости после проверки services. Full typecheck выполнить на общем пакете с layout, не параллельно с другими full builds.
