Старый smoke с --disable-workspace-trust не заменяет эти проверки. GUI только native CUA; не использовать CDP/Playwright для управления приложением.

Native QA: production package и ad-hoc signing прошли. Найден release blocker: onDidChangeRunningExtensions автоматически вызывает gallery getExtensions для отсутствующего в installed development/runtime extension; Chromium netlog и process socket подтвердили Open VSX запрос. ЗАНЯТО интегратором: extensionsWorkbenchService.ts и его целевые tests — убрать фоновый gallery lookup, сохранить локальное runtime tracking и ручной marketplace. Source freeze e132 временно superseded только этим обнаруженным исправлением; публикация до повторного QA запрещена.

Исправление готово: runtime add/remove обновляет локальные записи без gallery lookup; workspace resource extensions и ручные gallery/update операции сохранены. Regression test покрывает startup/add/remove development extension.
