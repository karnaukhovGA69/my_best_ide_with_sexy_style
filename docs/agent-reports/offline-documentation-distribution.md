# Поставка съёмного пакета документации — задача #9

Статус: правила сборки подготовлены. Проверка в упакованной IDE ожидает объединения с просмотрщиком и пакетом данных.

- Список поставки оставляет встроенный просмотрщик. `.vscodeignore` исключает официальный снимок при упаковке расширения через VSCE. Поздний фильтр сборки исключает те же файлы при чтении уже существующего `.build/extensions`. Исходники снимков сохранены для сборки отдельного VSIX.
- На macOS ARM64, Node 24.22.1: `node --test build/lib/test/distributionExtensions.test.ts` — 4/4. Тот же `vsce.listFiles`, который вызывает сборка, вернул 19 файлов просмотрщика, включая манифест, host и JS чтения. Дерево `documentation/` отсутствовало. `git diff --check` прошёл.
- Приёмка QA выполняется на подписанном кандидате. Проверить содержимое приложения и отдельного VSIX, затем в двух профилях с общим каталогом расширений проверить установку, выключение, повторное включение и удаление. После удаления из первого профиля и полного перезапуска второй продолжает читать статьи. После удаления из второго и полного перезапуска каталог пакета исчезает. Личные статьи читаются на всех этапах, их содержимое совпадает с исходным. Для автономной установки проверить отсутствие запроса к Open VSX по #16.
