# Подключение отдельного архива офлайн-документации

Задача #9, второй этап. Читатель получает каталог из `extensionUri` включённого `myself.offline-documentation` через публичный API VS Code. Он отслеживает событие `extensions.onDidChange` и использует путь и версию пакета для определения смены снимка. Расширение с данными может оставаться неактивным. Личные импорты по-прежнему загружаются из состояния профиля и доступны во время загрузки каталога. В checkout или переходной сборке встроенный снимок читается при отсутствии зарегистрированного пакета, пока соответствующие файлы существуют.

- После исчезновения или замены пакета меняется дерево библиотеки. Поздние результаты чтения и устаревшие официальные результаты поиска отбрасываются.
- Открытая личная статья сохраняет положение и получает только обновление состояния Back, если оно необходимо. При удалении открытой официальной статьи просмотр очищается. Back ведёт к предыдущей личной статье, если она осталась в истории. Скрытый читатель применяет новое состояние после показа и готовности webview.
- Reader принимает только локальную папку пакета. Файлы ограничены каталогом по каноническому пути, ссылки в пути не принимаются. Читаются только обычные файлы UTF-8, не более 4 МиБ для каталога и 16 МиБ для каждой статьи. При чтении проверяется размер и соответствие открытого файла текущему пути. Провайдеры других схем не используются. CSS, CSP, Webview Resource Roots и фильтрация HTML остались прежними.
- Ни `libraryImport.ts`, ни сборщик VSIX, ни упаковка приложения в этой ветке не менялись. Тест custom editor получил заглушку нового обращения к штатному API `vscode.extensions`.

## Проверки

На macOS arm64 с Node 24.22.1 и pnpm 12.16.0 выполнена команда `pnpm --dir extensions/myself-documents test`. Компиляция host и webview, 65 тестов node:test и Playwright прошли. Host-тесты используют реальные временные каталоги со снимком, имитируют регистрации VS Code и проверяют fallback, установку, отключение, повторное включение, замену версии, личный профиль, гонки и ограничения чтения. В браузере проверены очистка статьи, Back, сохранение прокрутки, чтение пяти наборов и отсутствие сетевых запросов при чтении. `git diff --check` прошёл.

Интегратору нужно подключить отдельную упаковку и правила исключения `documentation/**` из базовой сборки. Независимый smoke выполняется на готовой IDE с чистыми тестовыми `--user-data-dir` и `--extensions-dir`. Проверить библиотеку до установки VSIX, после установки, отключения, повторного включения и удаления. Проверить личный профиль, правую панель, Back, отсутствие фоновой сети, физическое удаление установленного архива после предусмотренной VS Code очистки и отсутствие дубля в приложении. Если VS Code предлагает перезапуск extension host, перепроверить библиотеку после перезапуска. Windows и Linux в этой ветке не запускались.
