# Ядро экспорта PDF с директивами

Задача `pdf-macros-backend`, база `e1d30d01782`, ветка `codex/pdf-macros-backend`, коммит реализации и тестов `35f2e336cebd90422bc6e3721a97b0163f5a0c63`. Изменения ограничены `src/vs/platform/documentExport/**` и этим отчётом. Ядро готово к независимому ревью. Команда и флажок в редакторе требуют подключения.

В режиме `version: 2, format: 'directives'` строки `@title Текст` и `@note Текст` становятся оформленными блоками, а `@page` начинает следующую непустую часть с новой страницы. Начальные, конечные и повторные разрывы, в том числе через пустые строки, учтены при группировке. Начальное `@@` даёт буквальный `@`. Неизвестные, неполные, регистрово отличающиеся и отступленные команды остаются текстом. Все части экранируются, а HTML и CSS заданы в коде. Запрос v1 сохраняет буквальный текст, прежний HTML и параметры страницы. Обе версии возвращают прежние результаты `saved` и `cancelled`.

Лимит 2 МиБ UTF-8 сохранён для обеих версий. Директивы ограничены 128 фактическими ручными разрывами и 4096 заголовками и примечаниями вместе. Без отдельных лимитов короткие строки объёмом до 2 МиБ могут потребовать сотни тысяч дополнительных страниц или элементов. Проверки выполняются при подготовке HTML до Save Dialog и до создания сессии Electron. Обычный текст сохраняет прежний лимит и естественное разбиение на страницы. Используются прежние CSP, блокировка навигации и запросов, изолированная сессия и атомарная запись. При отказе пользователь может снова вызвать обычный экспорт.
