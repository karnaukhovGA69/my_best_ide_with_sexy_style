# Вывод и остановка запущенных задач

Задание `project-task-output`, направление №26. База `e1d30d017826f23b582334df6d3e6606449bc021`, ветка `codex/project-task-output`, коммит реализации и тестов `dd309b3b7e938a7bb03f7778ba30f969c02d5a5f`. Область: `src/vs/workbench/contrib/myselfProjectProcesses/**` и этот отчёт. Владелец подключения и пакетной проверки — интегратор.

В группе проектных действий меню Terminal появился пункт **Running Project Tasks…**. Он показывает активные запуски из штатного Tasks. Путь рабочей папки и номер строки в текущем списке помогают отличить запуски с одинаковым именем. После выбора доступны **Show Terminal Output** и **Stop Task**. Первый пункт открывает существующий терминал соответствующей задачи. Второй вызывает остановку через Tasks, сохраняя его обработку завершения. Пустой список и завершившийся запуск дают короткое сообщение, отмена закрывает выбор.

Код ждёт инициализации Workspace Trust и проверяет доверие до чтения активных задач. Снимок относится к исходному workspace ID. После обоих выборов код получает актуальные запуски и проверяет исходный объект `Task` по ссылке, затем повторно сверяет ID workspace и доверие. `TerminalTaskSystem.run` создаёт отдельный объект на запуск, а ключ завершившегося запуска может быть переиспользован. Если исходный запуск завершился во время выбора, действие отменяется даже при повторном запуске задачи с тем же ключом. Внутреннее выполнение `ITaskService.terminate` остаётся штатным и повторно проверяет доверие. Вывод открывается только при однозначном соответствии задачи и существующего терминала по ресурсу от `getTerminalsForTasks`. Если терминал исчез или соответствие неоднозначно, показывается сообщение о недоступности вывода. Работа ограничена исполнениями Tasks текущего окна, вывод остаётся в терминале.
