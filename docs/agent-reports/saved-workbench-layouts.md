# Сохранённые раскладки панелей

Задача `saved-workbench-layouts`, направление №27. База `e1d30d01782`, ветка `codex/saved-workbench-layouts`. Область изменений — `src/vs/workbench/contrib/myselfLayouts/**` и этот отчёт.

Обычная команда Customize Layout меняет текущее окно. Подменю **View → Panel Layouts** позволяет сохранить состояние под именем и вернуться к нему позже. Снимок хранит видимость основной и дополнительной боковых панелей, видимость рабочей панели и выбранное представление каждого видимого места. Для видимой рабочей панели сохраняются положение и применимое выравнивание. Замена существующего имени и удаление требуют подтверждения. Применение начинается после выбора снимка.

Записи находятся в локальном хранилище профиля с `StorageScope.PROFILE` и `StorageTarget.MACHINE`. Профили, использующие общие данные профиля по умолчанию, видят эти сохранения в соответствии со своим выбором. У каждого снимка отдельная запись. Смена профиля во время диалога отменяет операцию. Действия проверяют актуальность записи после выбора и подтверждения. Повреждённые данные и неподдерживаемые версии схемы пропускаются.

## Границы

- Ранний наблюдатель подписывается только на смену профиля. Интерфейс и контроллер создаются после восстановления workbench. Снимки применяются только через команду пользователя. Тема, редакторы, вкладки, черновики и `settings.json` остаются под управлением существующих сервисов.
- Положение боковой панели задаёт `workbench.sideBar.location`. В `IWorkbenchLayoutService` есть чтение этой позиции, а setter внутри layout приватный. На этом этапе снимок управляет видимостью боковых панелей и их представлениями. Положение и выравнивание сохраняются для видимой рабочей панели.
- Применение ждёт готовности Workspace Trust и перепроверяет доверие при асинхронном открытии представлений. Оно выбирает контейнер по зарегистрированному ID только в исходном месте. Исчезнувший или перемещённый контейнер пропускается с уведомлением. Это исключает подстановку панели по умолчанию, поскольку `setPanelPosition` открывает скрытую рабочую панель. При явном восстановлении доступного Terminal в доверенном окне действует стандартное поведение Terminal View, которое может создать терминал.

## Проверки

- На `a1efbf5f56d` воспроизвёл ошибку с настоящими `RemoteStorageService` и `UserDataProfileService`. Смена между двумя недефолтными профилями, разделяющими глобальное хранилище по умолчанию, завершилась до создания контроллера. Сервис оставил идентичность первого профиля, поэтому проверка нового профиля не разрешала сохранение.
- Наблюдатель создаётся на BlockStartup и запоминает наблюдавшегося владельца общей базы. Контроллер ждёт завершения самой смены и ещё незавершённого предшествующего перехода, если база осталась общей. Хранилище подтверждает через `hasScope` текущий профиль или конкретного наблюдавшегося владельца этой базы.
- 15 целевых тестов прошли. Сценарии с реальным `RemoteStorageService` используют локальный in-memory канал. Проверены завершённое переключение до создания контроллера, несоответствующая база, открытие базы с задержкой, два общих профиля подряд при незавершённом переходе. Остальные тесты используют `InMemoryStorageService` и `UserDataProfileService` с подставными layout/view сервисами и проверяют сохранение, отмену, подтверждения, применение, отсутствие контейнера, повреждённые записи и потерю доверия.
- Тест собран отдельным esbuild во временном каталоге и запущен через `node --test` с адаптером `suite/test/setup/teardown` и глобальным `window` для импорта browser-модулей. Node 26.8.2, macOS ARM64. Приложение и терминал не запускались.
- TypeScript 6.0.3 с настройками `src/tsconfig.json`: синтаксические и семантические диагностики в пяти новых файлах отсутствуют. `git diff --cached --check` прошёл. Репозиторный ESLint и нативный сценарий остаются для приёмки после общего подключения.

## Подключение

Интегратор добавляет в desktop entrypoint `src/vs/workbench/workbench.desktop.main.ts`:

```ts
import './contrib/myselfLayouts/browser/savedPanelLayouts.contribution.js';
```

В workbench-секцию `build/lib/i18n.resources.json` добавить `vs/workbench/contrib/myselfLayouts` с проектом `vscode-workbench`. Зависимости, product и allowlist не меняются.

Для нативной приёмки сохранить два снимка с Files или SCM и с дополнительной панелью справки. При применении сверить видимые представления и положение рабочей панели. Проверить сохранённый снимок после обычного перезапуска, выбор в другом профиле, отмену удаления, недоступную справку и Restricted Mode. Открытый редактор с несохранённым текстом должен сохранить вкладку и текст при переключении раскладки.
