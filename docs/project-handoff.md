# Передача контекста: Myself IDE

Сводка на 4 ноября 2026 года для нового чата или отдельного агента. Не нужно перечитывать всю переписку. Сначала прочитай этот файл, затем AGENTS.md, своё задание и актуальный git status. Документы описывают состояние на дату записи; текущую готовность проверяй по коду и отчётам.

## Идея и границы

Владелец хочет собственную IDE на основе уже существующего форка Code - OSS: меньше лишних функций/кнопок и фоновой аналитики, новые документы/справка/GitHub-навигация и позже другой UI. Рабочее имя Myself IDE. Репозиторий: https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style. Не начинать новый форк, не трогать оригинальный VS Code/baseline и не fetch/merge/push upstream. Работать только с текущими наработками; origin — репозиторий владельца.

Не путать упрощение с полным переписыванием редактора. Не обещать меньший RAM/быстродействие без замеров. Полный каталог решений: [project-plan.md](project-plan.md).

## Ключевые договорённости переписки

- Убираем встроенные Copilot/AI/Chat/Sessions/MCP/voice и аналитику. Обычный IntelliSense (методы после точки, типы, параметры, диагностика) нужен.
- Публичная поставка без предустановленных языковых расширений, но с Git/Markdown/темами/служебными builtins. Extension host/API, Open VSX, VSIX и ручное обновление сохраняем. Не удалять пользовательские расширения и не обещать совместимость со всем Marketplace.
- Персонально владелец хочет Rust, C++, F#, Lua, Go, Docker, YAML, JSON, SQL. Это локальная установка, не состав GitHub-релиза. Позднее общее правило языков перекрывает ранние отдельные галочки L01–L18.
- Git/GitHub-аутентификация, SSH, терминал/Tasks, настройки и обычные инструменты разработки остаются. Grunt/Gulp/Jake не нужны; Tasks не удалять вместе с ними.
- Удалить пользовательский мультикурсор, встроенный format-on-save, палитру команд, Sticky Scroll, рекомендации и автообновления расширений. Новые функции обязаны иметь доступные кнопки/меню. Не вырезать API, необходимое сохраняемым сценариям, без анализа потребителей.
- Локальная история файлов/проектов/терминала остаётся. Локальные warning/error логи нужны для ремонта; не отправлять их автоматически. Цель — небольшой объём без постоянного тяжёлого сборщика.
- Своего сервера нет. Backup настроек планируется по желанию в приватный GitHub repo; предложить восстановление, не перезаписывать автоматически, не сохранять токены/ключи.
- Каталог репозиториев: одна выбранная папка; поиск по имени; если репозитория нет — clone с прогрессом, если есть — открыть без pull/reset. Не искать копии по всему компьютеру.
- Библиотека документации: локальные Markdown/PDF, справка IDE/языков, просмотр рядом с кодом; загрузка справочников позже.
- Документы: обычный текст учебных ответов/эссе → PDF видимой кнопкой, без TeX/облака. Полная замена Pages не требуется в первом MVP.
- Терминал: исследовать Ghostty/другой движок; встроить отдельное приложение простым профилем shell нельзя обещать. Если дорого — штатный терминал с настройками/shell-плагинами, затем внешняя интеграция.
- Визуальный ремастер: свой бренд/эмблема, форма кнопок, панели, цвета, настраиваемая плотность/скругления. Пока не сделан и не требует переписывания всей базы.
- Основные результаты должны попадать в origin/main, а не оставаться в phase-ветках. Публичную историю не переписывать. Использовать GitHub noreply и существующие privacy guards; старые приватные идентификаторы не повторять в отчётах. Новое обращение в поддержку для удаления старого кэша пользователь не просил.
- Полный build/package/smoke/release делать на пакет изменений. Не после каждого коммита, завершения агента или сообщения «дальше». Документы — без сборки; на коде целевые проверки. См. AGENTS.md.

## Что реально сделано

Шесть этапов очистки объединены в main; седьмой добавил PDF. Бинарный релиз [v0.0.7-preview](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/releases/tag/v0.0.7-preview) собран из `99373603913f162e9d1256cc621949b8bdef03c0`. Правило пакетных сборок добавлено следующим коммитом `01293638a16`. Новые чаты стартуют от актуального main, не от старых phase-веток. На момент проверки открытых PR не было.

- Своя product identity и пользовательский каталог. Builtin allowlist — build/lib/distributionExtensions.ts (36 компонентов при проверке). Языковые расширения/Copilot/Emmet/Grunt/Gulp/Jake не поставляются.
- Фильтры distributionRuntime и production entrypoints исключают Sessions/Agent Host/local transcription и ряд AI SDK. Общие AI/MCP исходники/контракты и зависимости остаются.
- Телеметрия/IDs/эксперименты/crash upload заблокированы. Рекомендации и автообновления расширений не запускаются; ручной каталог/VSIX/update работает.
- Inline Chat и Terminal Chat больше не регистрируют основные контроллеры/действия. Совместимые сервисы отключены; оставшиеся terminal chat tools — отдельная задача.
- Пользовательские действия палитры/мультикурсора/Sticky Scroll/format-on-save убраны. Snippet suggestions и Welcome отключены по умолчанию; не весь исходный код удалён.
- Tasks исправлены для поставки без языковых расширений: пустые pattern/matcher registries инициализируются при регистрации расширений, shell task завершается.
- Native logs: warning/error по умолчанию, 2 MiB + 4 backup на канал, ротация при записи в новый UTC-день; часть старых файлов очищается после 7 дней. Это не общий лимит всех логов/Output/расширений.
- PDF implementation: src/vs/platform/documentExport/**, src/vs/workbench/contrib/documentExport/**. NativeHost/desktop entrypoint уже подключены. Extension DTO: myself.documents.exportPdf; команда видимой кнопки: myself.documents.exportActiveTextPdf. Контракт в document-export-contract.md.
- PDF: текущий буфер → native Save Dialog → локальный Electron printToPDF → атомарная запись. A4/20mm/serif12pt/1.5, лимит 2 MiB UTF-8, экранирование текста, sandbox/без сети и JS, временное окно и cleanup. Markdown/HTML печатаются буквально. UI настроек страницы ещё нет.

## Проверки и известные ограничения

Для седьмого этапа прошли client typecheck, targeted lint, unit tests, native PDF cancel/concurrency/write failure/cleanup, визуальная и текстовая проверка PDF на 1 и 6 страниц, ручная кнопка/Save Dialog. Общий packaged smoke: Git, bash/zsh, shell Tasks exit0, completion, ручное форматирование, отсутствие format-on-save, VSIX install→update→uninstall. Пакет прошёл build-path scan, подпись, ASAR size check и ZIP audit; публичный digest/tag проверены.

Один обычный профиль при ручном запуске показал пустое окно. Причина не установлена; изолированный профиль успешно открыл файл и экспортировал PDF. Не объявлять это исправленным и не сбрасывать пользовательский профиль без причины. macOS ARM64 — проверенная платформа; приложение ad-hoc signed, не notarized. Другие ОС/SSH не проверены. Собственная OAuth identity GitHub ещё не настроена. Не заявлять, что весь AI физически удалён или все сторонние расширения лишены сетевых запросов.

## Что дать новому чату

Скопировать блок, подставив один task-id, предварительно проверив, что он свободен:

```text
Продолжаем Myself IDE в существующем форке karnaukhovGA69/my_best_ide_with_sexy_style.
Моё задание тебе: <task-id>.
Прочитай AGENTS.md, docs/project-handoff.md, docs/project-plan.md,
docs/development-plan.md, docs/agent-reports/integration.md и соответствующий
промпт в docs/agent-prompts/. Затем проверь git status, базу и владельца области.
Работай только в своей области и отдельном назначенном checkout/ветке от текущего main.
Оригинальный VS Code и upstream не трогай. PDF backend уже готов.
Не запускай других агентов автоматически. Используй целевые проверки.
Полные сборки выполняет интегратор на пакет изменений перед релизом.
Оставь код, коммит и отчёт с реальными проверками и необходимыми подключениями.
```

Если новый чат продолжает роль интегратора, явно назначить ему integration и передать владение от прежнего чата. Этот документ сам по себе не запускает новых агентов и не передаёт им общие файлы.
