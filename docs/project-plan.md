# Myself IDE — цель и полный план

Сводка решений с обновлением от 6 ноября 2026 года. Название Myself IDE рабочее; репозиторий — `karnaukhovGA69/my_best_ide_with_sexy_style`. Этот документ описывает желаемый продукт и явно отличает его от текущей реализации. Точный статус кода — в [myself-ide.md](myself-ide.md), порядок работы — в [development-plan.md](development-plan.md).

## Цель

Сделать собственную настраиваемую IDE на основе уже созданного форка Code - OSS: проще по интерфейсу и составу, с полноценными инструментами разработки, без встроенного AI-блока и аналитики. Добавить удобные документы, локальную справку и перенос настроек через файл. Облегчение должно затрагивать загружаемый код и состав поставки, а не только скрывать кнопки. Снижение размера, RAM и времени запуска — цели, которые ещё нужно измерить отдельно.

Нового редакторного движка с нуля не пишем. UI можно менять постепенно в существующей архитектуре. Electron и совместимость расширений пока остаются основой; радикальное переписывание проекта не согласовано.

## Оставляем

- Файлы/папки, Explorer, несколько проектов и окон, поиск/замену, навигацию, undo/redo, autosave, восстановление и полезную локальную историю. Штатную защиту при работе с большими файлами сохраняем.
- Подсказки существующих методов/полей/типов, hover, параметры функций, диагностику, переходы, переименование и рефакторинг. Языковые возможности предоставляет установленное пользователем расширение; их API не вырезаем вместе с AI.
- Расширения и extension host/API, ручную установку/обновление, собственные расширения, форматтеры и линтеры. Каталог сейчас Open VSX; ручной VSIX обязателен. Полную совместимость со всеми расширениями Microsoft не обещаем.
- Обычные Git-операции, SSH, локальные репозитории и общий API аутентификации расширений. Собственные GitHub OAuth/catalog/backup исключены из плана; GitHub-специфичные модули удалять после проверки потребителей.
- Терминал, bash/zsh, shell integration, историю, splits, shell-плагины, Tasks и npm scripts. Готовые интеграции Grunt/Gulp/Jake убираем; сам механизм Tasks оставляем.
- SSH и инфраструктуру удалённой разработки, отладку, Test Explorer и покрытие. Наличие кода не равно проверенной доступности каждого сервиса в форке.
- Настройки, горячие клавиши, профили, темы, вкладки, панели, локализацию, Zen Mode. Markdown, Mermaid, математику, media preview, notebooks, webviews/custom editors и браузерные поверхности.
- Локальные технические логи и Output для диагностики, без автоматической отправки. Process Explorer нужен для поиска нагрузки.

## Удаляем и упрощаем

| Направление | Решение | Что уже сделано / что осталось |
| --- | --- | --- |
| Встроенный AI | Убрать Copilot, чат, агенты/Sessions, модели, MCP, голос, генеративные inline-подсказки, AI trackers | Расширение Copilot и ряд runtime-компонентов исключены; регистрации/пути inline chat, terminal chat и Sessions отключены. Общие Chat/MCP/API и зависимости остаются для дальнейшей очистки |
| Аналитика | Убрать сбор/отправку статистики, аналитические IDs, эксперименты, crash/error upload и опросы | Встроенные пути телеметрии/экспериментов/crash reporting заблокированы. Не весь исходный код reporters физически удалён; политику сторонних расширений не контролируем автоматически |
| Предустановленные языки | Убрать языковые расширения из публичной поставки | Сделан allowlist; языковые исходники ещё могут существовать в checkout. Пользователь может установить нужный язык |
| Рекомендации и автообновления расширений | Убрать рекомендации, фоновые проверки/установки и автоматические перезапуски | Соответствующие runtime-регистрации и настройки убраны; ручное управление сохранено |
| Палитра команд | Удалить пользовательскую палитру | Провайдер/основная команда/меню удалены; API выполнения команд сохранён. Новым функциям нужны видимые кнопки/меню |
| Мультикурсор | Удалить пользовательские действия и жесты | Удалены регистрации; внутренние multi-edit механизмы для rename/расширений остаются |
| Format on save | Удалить встроенный автозапуск форматирования | Убран; ручной formatter через расширение работает. Стороннее расширение может иметь свой save hook |
| Sticky Scroll, Emmet, Grunt/Gulp/Jake | Убрать эти встроенные возможности | Sticky Scroll не загружается; остальные исключены из поставки |

| Welcome/walkthrough | Убрать стартовое обучение и лишние экраны | Welcome отключён по умолчанию, весь код ещё не удалён |
| Остальные отмеченные удаления | GitHub без клонирования, обновление IDE, UI доступности, profiling/devtools, Issue Reporter, опросы | Это решения чеклиста, не отчёт о выполнении. Нужен отдельный аудит зависимостей; не вырезать автоматически общие службы, клавиатурную навигацию и необходимые диагностические механизмы |
| Облачный Settings Sync | Заменить локальным экспортом/импортом настроек | Файл переносится пользователем; без входа, сервера и токенов |

Фоновый Git fetch в чеклисте оставлен. «Без аналитики» не означает «без сети» или «без полезной локальной истории».

## Порядок работы

1. Ближайший пакет: documents-ui + mcp-gallery-disable (обе задачи уже заняты отдельными агентами); затем готовые результаты очистки terminal AI-инструментов и дальнейшего MCP audit. PDF backend уже готов. Зафиксировать владельцев; отдельно расследовать замеченное пустое окно обычного профиля, не сбрасывая пользовательские данные.
2. Следующий пакет после аудита: безопасная очистка MCP/общего AI и оставшихся пунктов удаления. Сохранить IntelliSense, extension API, Git, терминал и Tasks.
3. Локальный перенос настроек: экспорт → проверка импортируемого файла → явный выбор применения. GitHub-пакет отменён.
4. Документация и удобство: локальная библиотека/загрузка справочников, диагностика/общий бюджет логов, личный языковой набор.
5. Терминальный прототип и визуальный ремастер — отдельные задачи с оценкой результата и стоимости перед глубокими изменениями.

Это порядок по зависимостям, без обещаний сроков. Независимые области можно делать параллельно. Один агент владеет одной областью, интегратор — общими файлами и релизом. Несколько изменений накапливаем в пакет; один общий build/test/release. Между ними только необходимые целевые проверки. Новая реплика «дальше» не требует нового релиза.

Последний проверенный бинарный preview на момент этой сводки — [v0.0.7-preview](https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style/releases/tag/v0.0.7-preview), исходный коммит `99373603913f162e9d1256cc621949b8bdef03c0`. Не объявлять SSH, все расширения и другие ОС проверенными.
