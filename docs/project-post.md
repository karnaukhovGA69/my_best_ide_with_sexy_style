# Текст для поста

Делаю свою IDE на базе Code - OSS. Пока называю её Myself IDE — название ещё рабочее.

Идея простая: оставить удобные инструменты разработки и убрать то, чем я не пользуюсь. Git, терминал, расширения, подсказки методов, отладка и Markdown остаются. Встроенный AI-блок, аналитика, рекомендации и часть перегруженного интерфейса постепенно уходят. Языки каждый сможет поставить сам, без предустановленного набора за него.

Уже есть тестовая сборка для Mac на Apple Silicon, ручная установка расширений и локальный экспорт обычного текста в PDF. Можно написать ответы по английскому или эссе и сохранить PDF без TeX. Дальше хочу добавить красивый редактор документов, библиотеку справки рядом с кодом и список своих GitHub-репозиториев: нажал — скачал или открыл уже имеющийся, без автоматического обновления проекта.

Отдельная большая цель — новый настраиваемый интерфейс и более удобный терминал. Разрабатываю проект вместе с AI-агентами, хотя встроенный AI в самой IDE мне не нужен.

Это пока эксперимент: общий AI/MCP-код ещё очищаем, дизайн впереди, а выигрыш по памяти и скорости предстоит измерить. Делаем изменения пакетами и проверяем их вместе перед релизом.

Репозиторий: https://github.com/karnaukhovGA69/my_best_ide_with_sexy_style
