NAME

mansectf - format specific sections of manual pages

SYNOPSIS

mansectf section [file ...]

DESCRIPTION

The mansectf command formats specific sections of manual-page files.

PARAMETERS

See mansect(1).

ENVIRONMENT

See man(1).

EXAMPLES

$ man -w strtol strtoul | xargs mansectf 'NAME|SEE ALSO' | cat;
