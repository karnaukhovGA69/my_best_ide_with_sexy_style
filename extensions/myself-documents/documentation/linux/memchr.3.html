NAME

memchr - memory search character

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <string.h>  // see memory.h(3head)
void *memchr(size_t n;
             const void s[n], int c, size_t n);

DESCRIPTION

memchr() scans the initial n bytes of the memory area pointed to by s for the first instance of c.

Both c and the bytes of the memory area pointed to by s are interpreted as unsigned char.

RETURN VALUE

memchr() returns a pointer to the matching byte or NULL if the character does not occur in the given memory area.
