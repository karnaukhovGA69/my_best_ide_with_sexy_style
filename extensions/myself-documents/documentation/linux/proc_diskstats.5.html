NAME

/proc/diskstats - disk I/O statistics

DESCRIPTION

/proc/diskstats (since Linux 2.5.69)
This file contains disk I/O statistics for each disk device. See the Linux kernel source file Documentation/admin-guide/iostats.rst for further information.
