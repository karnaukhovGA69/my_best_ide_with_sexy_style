NAME

strndupa - nonstring duplicate-into-string using-alloca

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#define _GNU_SOURCE  /* See feature_test_macros(7) */
#include <string.h>  // see memory.h(3head)
char *strndupa(size_t n;
              const char strn[n], size_t n);

DESCRIPTION

strndupa() is similar to strndup(3), but uses alloca(3) to allocate the buffer.

It is equivalent to


strncat(strcpy(alloca(n + 1), ""), strn, n)

RETURN VALUE

On success, this macro returns a pointer to the duplicated string.
