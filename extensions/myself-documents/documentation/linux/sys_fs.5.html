NAME

/sys/fs/ - filesystems

SYNOPSIS

/sys/fs/

DESCRIPTION

This directory contains subdirectories for some filesystems. A filesystem will have a subdirectory here only if it chose to explicitly create the subdirectory.

/sys/fs/cgroup/
See sys_fs_cgroup(5).
/sys/fs/smackfs/
See sys_fs_smackfs(5).

STANDARDS

Linux.

HISTORY

Linux 2.6.0.
