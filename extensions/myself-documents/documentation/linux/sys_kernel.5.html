NAME

/sys/kernel/ - information about the running kernel

SYNOPSIS

/sys/kernel/

DESCRIPTION

This subdirectory contains various files and subdirectories that provide information about the running kernel.

/sys/kernel/cgroup/
See sys_kernel_cgroup(5).
/sys/kernel/debug/
See sys_kernel_debug(5).
/sys/kernel/mm/
See sys_kernel_mm(5).

STANDARDS

Linux.

HISTORY

Linux 2.6.0.
