NAME

/sys/kernel/debug/ - debugging

SYNOPSIS

/sys/kernel/debug/

DESCRIPTION

/sys/kernel/debug/tracing
Mount point for the tracefs filesystem used by the kernel's ftrace facility. (For information on ftrace, see the kernel source file Documentation/trace/ftrace.rst.)

STANDARDS

Linux.

HISTORY

Linux 2.6.0.
