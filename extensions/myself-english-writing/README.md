# Nerded Code English Writing

Open **English Writing** from the editor toolbar or context menu in a Markdown or plain-text document. **Show Problems** opens the editor's diagnostics panel. **Show Code Actions** opens the editor's menu of possible fixes. **Analyze Text** opens the local Text Analyzer panel.

**Writing Tool Availability** shows which optional tools this window can see. For a missing tool, enable its extension or choose **Install from VSIX…** in the Extensions menu and select a local VSIX. The optional extensions are Harper (`elijah-potter.harper`) and Text Analyzer (`iglou-eu.text-analyzer`). Diagnostics and suggested edits are controlled by the editor and its active providers.
