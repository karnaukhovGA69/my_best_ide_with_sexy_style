All 1,664 SVG assets from the release are included. The file associations,
language associations, light variants and folder states are retained. The
manifest's relative icon paths were rebased for this package. Language
extension fallback icons are disabled so that this theme uses local assets.

Empty script/link elements were removed from eight SVG files (affinity,
alchemy, electron, gimp, nushell, polyglot, vvvvvv and xaml). No artwork was
recolored, redrawn or replaced. fileicons/provenance.json records original
and bundled SHA-256 hashes, archive identity and all modified filenames.

Only declarative resources are bundled. The upstream extension's executable
code, project detection, commands, configuration and update behavior are
not included.
